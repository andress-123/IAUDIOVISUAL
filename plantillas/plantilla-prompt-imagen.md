# Plantilla — Prompt de imagen

Copia y rellena:

```
Sujeto: 
Acción/pose: 
Entorno/contexto: 
Estilo (arte/foto/referencia): 
Iluminación: 
Composición/encuadre: 
Detalles técnicos (lente, cámara, render): 
Parámetros de la herramienta (aspect ratio, --style, --v, etc.): 
Negativo (qué evitar): 
```

Ver `recursos/metodologias/estructura-de-prompts.md` para la lógica detrás de cada campo.
