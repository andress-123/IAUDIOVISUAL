# Glosario de prompting IA (imagen y vídeo)

- **Prompt positivo:** el texto que describe lo que se quiere generar.
- **Prompt negativo:** el texto que describe lo que se quiere evitar.
- **Peso/weight:** énfasis dado a una palabra o frase (p. ej. `(atardecer:1.4)`).
- **Seed:** número que fija el punto de partida aleatorio, permite reproducir o variar ligeramente un resultado.
- **Aspect ratio:** proporción de la imagen/vídeo (16:9, 9:16, 1:1...).
- **Style reference / image reference:** imagen que se usa para guiar el estilo o el contenido.
- **Character reference:** imagen de referencia para mantener un personaje coherente.
- **LoRA:** modelo pequeño entrenado para reproducir un estilo, personaje o concepto concreto.
- **Camera control / motion control:** parámetros o técnicas para dirigir el movimiento de cámara en vídeo.
- **Text-to-image / Text-to-video:** generación a partir solo de texto.
- **Image-to-video:** generación de vídeo a partir de una imagen de partida.
- **Upscale:** aumento de resolución/calidad de una generación.
- **Inpainting / Outpainting:** edición de una parte concreta de la imagen / extensión del lienzo más allá de los bordes originales.

_Se amplía a medida que aparecen términos nuevos en los recursos recopilados._
